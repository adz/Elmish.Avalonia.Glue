Packaging fix release.

## Fixed

- `Elmish.Avalonia.Glue.Testing` is published to NuGet. Release 0.2.0 built and attached it to the GitHub
  release but left it out of the NuGet publish step. The release workflow now fails if a packed package is
  missing from its publish list.

  `ElmishHost` and keyed-collection types, and links from guides to the API contract pages.
- Moved to FsLiveDocs 0.14.1. Each checked example shows the opens and types it needs and whether it is verified
  or an illustrative fragment, in the site and in `llms-full.txt`.

The API is unchanged from 0.2.0.
