First NuGet release.

- `Elmish.Glue.Core`: Elmish host, projections and keyed collection patching.
- `Elmish.Avalonia.Glue`: Avalonia 12 host on top of the core.
- `Elmish.Avalonia.Glue.Projection`: projection / snapshot-host approach.
- `Elmish.Avalonia.Glue.ElmView`: ElmView approach with design-time-friendly hosts.

- Hosted dispatch is serialized on the Avalonia UI thread, with inline delivery
  for on-thread model updates and a public `ElmishHost.post` callback.
- F# `ProjectionNode` provides change notifications; `SyncWith` accepts F# lists
  and sequences. Guides cover background dispatch, identity keys, and all-F# UI
  write-back registration via `ForPath`.

The API is pre-1.0 and may change between minor versions.
