First NuGet release.

- `Elmish.Glue.Core`: Elmish host, projections and keyed collection patching.
- `Elmish.Avalonia.Glue`: Avalonia 12 host on top of the core.
- `Elmish.Avalonia.Glue.Projection`: projection / snapshot-host approach.
- `Elmish.Avalonia.Glue.ElmView`: ElmView approach with design-time-friendly hosts.

The API is pre-1.0 and may change between minor versions.
