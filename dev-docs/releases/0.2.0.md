Second NuGet release.

## Fixed

- Worker-thread dispatch could corrupt Elmish's queue. Dispatch now goes through
  one ordered drain: the Avalonia host delivers inline when the UI thread is idle
  and otherwise queues work on the UI thread, queued worker messages cannot be
  overtaken, and each drain handles only a bounded snapshot. The core host
  provides the same FIFO serialization without thread affinity.
- Update failures propagate to the draining caller without wedging the queue;
  later dispatches resume the remaining messages.
- `SyncWith` duplicate-key failures report the offending key, and the
  keyed-collection guidance now stresses stable identity keys over display text.

## Added

- `ElmishHost.post`, an inline-or-post callback on the Avalonia package for
  runtime options that accept a posting function.
- F# `ProjectionNode` with `INotifyPropertyChanged`; `Change` raises a
  notification only when structural equality detects a changed value.
- `SyncWith` overloads accepting F# lists and sequences (converted to arrays
  before patching).
- `WriteBackBindings.ForPath` for F# callers registering writable ElmView paths
  without C# expression-tree selectors.
- The `Elmish.Avalonia.Glue.Testing` package for headless Avalonia testing:
  a real headless Skia surface plus `Headless.start`, `waitUntil`, and
  `captureFrame`, with no test-framework dependency. Headless tests cover
  dispatcher posting, ordered dispatch, bound rendering, and collection patching.

## Packaging

- Every package now carries a maturity rating in its tags and description:
  Incubating for `Elmish.Avalonia.Glue`, `Elmish.Glue.Core`, and
  `Elmish.Avalonia.Glue.Projection`; Experimental for
  `Elmish.Avalonia.Glue.ElmView` and `Elmish.Avalonia.Glue.Testing`.
- `Elmish.Avalonia.Glue.Testing` is included in the pack output, and release
  publishing now pushes symbols once via the `.nupkg`/`.snupkg` pair instead of
  submitting them twice.

## Documentation

- Generated API reference pages now attach behavioral contracts and failure
  modes to their entities, with runtime and collection reference material moved
  to reference pages.
- Added installation and compatibility guidance, a task index, an adapter
  decision table, glossary, troubleshooting matrix, and error-handling recipes.
- Added complete minimal Projection and ElmView screens, including F#, C#,
  AXAML, and application lifetime, verified by runnable docs examples.
- Added the all-F# Avalonia UI guide, including write-back registration with
  `ForPath`, and new background-command/threading guides.
- Rebuilt the newcomer learning path and migrated the docs site to FsLiveDocs.
  The docs build now compiles documented assemblies before extracting API docs
  and checks links, sidebar labels, and the package-maturity table.
- Added `llms.txt` for agent-friendly navigation.

The API is pre-1.0 and may change between minor versions.
