# Elmish.Avalonia.Glue.ElmView

The ElmView approach for Elmish + Avalonia: immutable F# view records bind to AXAML through thin generated
hosts that also work at design time, so there is little or no C#.

Pre-1.0: the API may still change between minor versions.

- Guide: https://adz.github.io/Elmish.Avalonia.Glue/docs/guides/understand/elmview-family
- Source: https://github.com/adz/Elmish.Avalonia.Glue
