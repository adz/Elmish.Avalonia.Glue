# Elmish.Avalonia.Glue.Projection

The projection approach for Elmish + Avalonia: write ordinary CLR viewmodels for your AXAML and project
the Elmish model into them, using snapshot hosts to keep those viewmodels shallow.

Pre-1.0: the API may still change between minor versions.

- Guide: https://adz.github.io/Elmish.Avalonia.Glue/guides/projection.html
- Source: https://github.com/adz/Elmish.Avalonia.Glue
