# Elmish.Glue.Core

Framework-neutral building blocks shared by the Elmish.Avalonia.Glue packages: an Elmish program host,
projections from model to bindable state, and keyed collection patching that updates an
`ObservableCollection` in place instead of replacing it.

Most apps reference [Elmish.Avalonia.Glue](https://www.nuget.org/packages/Elmish.Avalonia.Glue) (which
brings this in) rather than using it directly.

Pre-1.0: the API may still change between minor versions.

- Docs: https://adz.github.io/Elmish.Avalonia.Glue/docs/intro
- Source: https://github.com/adz/Elmish.Avalonia.Glue
