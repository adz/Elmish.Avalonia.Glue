# Elmish.Avalonia.Glue

Avalonia stays normal while immutable, Elmish-style F# state provides the UI
shape. The library supports both explicit `Projection` viewmodels and the
F#-first `ElmView` bindable-host path.

## Build this site

The site is generated by the repository-local FsLiveDocs .NET tool:

```bash
dotnet tool restore
dotnet build Elmish.Avalonia.Glue.sln
bash scripts/build-docs.sh
dotnet livedocs watch --host 127.0.0.1 --port 5000
```
